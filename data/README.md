# Dataset Information

This project uses the `BathHousePrices` dataset, supplied as an R data file named `BathHousePrices.rda` for the MA52115 Applied Statistics coursework at the University of Bath.

The dataset contains 350 property transactions and includes the following variables:

- `SalePrice` – property sale price (£).
- `Bedrooms` – number of bedrooms.
- `LivingArea` – internal living area (sq ft).
- `GarageCars` – number of garage spaces.
- `Garden` – indicates whether the property has a large garden.
- `DistFromSchool` – distance from the nearest school (miles).

## Data Availability

The original dataset is not included in this repository because it was supplied for academic coursework and is not publicly available.

An authorised copy of `BathHousePrices.rda` is required to run the analysis.

## Usage

Place the authorised `BathHousePrices.rda` file in the appropriate working directory before executing `bath_house_price_analysis.R`.
